# ⚡ Estruturas de Dados em C++

Este repositório contém uma coleção de implementações completas e didáticas de **Estruturas de Dados**, desenvolvidas em **C++**. O objetivo do projeto é demonstrar o uso eficiente de ponteiros, alocação dinâmica de memória e análise de complexidade algorítmica (Big O).

## 🗺️ Estrutura e Conteúdo

```text
┌────────────────────────────────────────────────────────┐
│                   ESTRUTURAS DE DADOS                  │

│         LINEARES          │        NÃO LINEARES        │
├───────────────────────────┼────────────────────────────┤
│  • Vetores (Arrays)       │  • Árvores Binárias (BST)  │
